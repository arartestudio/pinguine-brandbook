# pinguine · Brandbook

Brandbook de conceito da marca **pinguine**, agência de comunicação.
*Comunicação que move marcas.*

Site estático em um único `index.html`, com as imagens em `img/`.

## Conteúdo
Manifesto · Essência · Símbolo · Construção · Logotipo · Cores · Tipografia · Linguagem visual · Tom de voz · Aplicações

## Publicar no GitHub Pages
1. Suba estes arquivos para a raiz de um repositório.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. Em cerca de um minuto o site fica em `https://<usuario>.github.io/<repositorio>/`.

## Ver localmente
Abra `index.html` no navegador.
